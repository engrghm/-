# InvestPro — ক্রিপ্টো ইনভেস্টমেন্ট প্ল্যাটফর্ম

USDT / BTC / ETH বা যেকোনো কয়েনে বিনিয়োগ নেওয়ার ওয়েবসাইট: একাধিক প্ল্যান, দৈনিক/মাসিক কম্পাউন্ডিং,
"৪ বছরে দ্বিগুণ" প্ল্যান, ক্লায়েন্ট ড্যাশবোর্ড ও অ্যাডমিন প্যানেল।

## চালানো

Node.js 22.13+ লাগবে।

```bash
npm install
ADMIN_EMAIL=you@example.com ADMIN_PASSWORD='শক্ত-পাসওয়ার্ড' npm start
# http://localhost:3000
```

প্রথমবার চালু হলে `ADMIN_EMAIL` / `ADMIN_PASSWORD` দিয়ে অ্যাডমিন অ্যাকাউন্ট তৈরি হয়।
ডেটা থাকে `data/app.db` (SQLite) ফাইলে। প্রোডাকশনে `NODE_ENV=production` দিন এবং HTTPS-এর পেছনে চালান।

| ভ্যারিয়েবল | কাজ |
|---|---|
| `PORT` | পোর্ট (ডিফল্ট 3000) |
| `DB_PATH` | ডেটাবেস ফাইলের পাথ |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | প্রথম অ্যাডমিন অ্যাকাউন্ট |
| `NODE_ENV=production` | সিকিউর কুকি চালু করে |

টেস্ট: `npm test`

## লাইভ করা (ডিপ্লয়)

ডেটাবেস একটা SQLite ফাইল, তাই হোস্টে **স্থায়ী ডিস্ক (persistent disk/volume)** লাগবেই।
ডিস্ক ছাড়া চালালে প্রতিবার রিস্টার্টে সব ইউজার, ডিপোজিট ও বিনিয়োগের তথ্য মুছে যাবে।
এজন্য বেশিরভাগ হোস্টের ফ্রি প্ল্যানে চলবে না।

### Render (সবচেয়ে সহজ, মাসে ~৭ ডলার)
1. https://render.com এ GitHub দিয়ে সাইন আপ করুন।
2. **New → Blueprint** → এই রিপো (`engrghm/-`) বেছে নিন। `render.yaml` থেকে সব সেটিং নিজে থেকে আসবে।
3. `ADMIN_EMAIL` ও `ADMIN_PASSWORD` বসিয়ে **Apply** চাপুন।
4. কয়েক মিনিট পর `https://investpro-xxxx.onrender.com` ধরনের লিংকে সাইট চালু হবে।

### Railway (মাসে ~৫ ডলার)
1. https://railway.com → **New Project → Deploy from GitHub repo** → এই রিপো ও ব্রাঞ্চ বেছে নিন (`Dockerfile` নিজে থেকে ব্যবহার হবে)।
2. সার্ভিসে **Volume** যোগ করুন, mount path দিন `/data`।
3. Variables-এ `ADMIN_EMAIL`, `ADMIN_PASSWORD` দিন। Settings → Networking → **Generate Domain**।

### নিজের VPS (DigitalOcean, Hetzner ইত্যাদি)
```bash
docker build -t investpro .
docker run -d --restart unless-stopped -p 80:3000 -v investpro-data:/data \
  -e ADMIN_EMAIL=you@example.com -e ADMIN_PASSWORD='শক্ত-পাসওয়ার্ড' investpro
```
HTTPS-এর জন্য সামনে Caddy বা Nginx রাখুন (প্রোডাকশনে লগইন কুকি শুধু HTTPS-এ কাজ করে)।

### নিজের ডোমেইন
হোস্টের **Custom Domain** সেটিংসে ডোমেইন যোগ করে, ডোমেইন রেজিস্ট্রারে তাদের দেওয়া CNAME/A রেকর্ড বসান।

### ব্যাকআপ
`/data/app.db` ফাইলটাই পুরো ডেটাবেস। নিয়মিত এর কপি রাখুন।

## চালু করার পর প্রথম কাজ

1. `/auth` থেকে অ্যাডমিন হিসেবে লগইন করুন → `/admin`।
2. **ওয়ালেট** ট্যাবে নিজের আসল ডিপোজিট অ্যাড্রেস বসিয়ে "চালু" করুন। অ্যাড্রেস না দেওয়া পর্যন্ত কেউ ডিপোজিট করতে পারবে না।
3. **প্ল্যান** ট্যাবে প্ল্যানগুলো নিজের মতো ঠিক করুন।

## কীভাবে কাজ করে

- **প্ল্যান:** প্রতিটির মেয়াদ, APY, কম্পাউন্ডিং (দৈনিক/মাসিক), সর্বনিম্ন/সর্বোচ্চ সীমা আছে।
  মূল্য = `মূলধন × (1 + APY)^(দিন ÷ 365)`। ৪ বছরে ২x হতে APY = `2^(1/4) − 1 = 18.9207%`।
  অ্যাডমিন প্যানেলের "মেয়াদে ২x হওয়ার APY বসান" বোতাম যেকোনো মেয়াদের জন্য এটা হিসাব করে দেয়।
- **ডিপোজিট:** ক্লায়েন্ট দেখানো অ্যাড্রেসে কয়েন পাঠিয়ে TxID জমা দেয়। অ্যাডমিন ব্লকচেইনে যাচাই করে অনুমোদন দিলে
  বিনিয়োগ শুরু হয়। সব হিসাব USDT মূল্যে; BTC/ETH হলে অ্যাডমিন অনুমোদনের সময় USDT মূল্য বসান।
- **উত্তোলন:** মেয়াদ পূর্ণ হলে মূলধন + লাভ। মেয়াদের আগে তুললে শুধু মূলধন। অ্যাডমিন নিজে পেমেন্ট পাঠিয়ে পেআউট TxID দেন।
- প্ল্যান পরে বদলালেও চলমান বিনিয়োগের শর্ত বদলায় না।

পেমেন্ট যাচাই ও পেআউট দুটোই হাতে করতে হয়; কোনো ব্লকচেইন/পেমেন্ট গেটওয়ে যুক্ত নেই।
